# LM = YOU Introweek — alternatieve toegang

Dit repository publiceert automatisch een tweede toegang tot dezelfde LM = YOU
Introweek-app en dezelfde Supabase-productiedatabase.

- Hoofdadres: <https://lmyou.nl/>
- Alternatief adres: <https://inholland-lm.github.io/introweek-test/>
- Broncode: <https://github.com/Inholland-LM/Introweek-app>

De broncode in dit repository wordt niet handmatig bijgehouden. De GitHub
Actions-workflow bouwt iedere vijf minuten de actuele `main`-branch van het
bronrepository en publiceert die naar GitHub Pages.
